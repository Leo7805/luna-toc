# LunaTOC-SC — ChatGPT 中文对话目录

LunaTOC-SC 是面向 ChatGPT 长对话的中文 Chrome 浏览器扩展：将用户提问整理成可搜索的侧边栏目录，支持定位问题、浏览回答标题，以及在编辑历史问题后主动同步当前对话。

本仓库 **`PyRookie1/luna-toc-sc`** 基于开源项目 [Leo7805/luna-toc](https://github.com/Leo7805/luna-toc) 进行修改与维护。

## 功能

- **可搜索的对话目录**：自动整理 ChatGPT 对话中的用户提问，支持搜索、当前可见问题高亮，以及长对话中的虚拟滚动定位。
- **极简贴边自动隐藏**：目录侧边栏收起时，视口右缘仅保留 **5px 宽、上下铺满视口**的半透明蓝色触发条，不显示「目录」文字或月牙图标，也不读取旧版拖动位置。鼠标移入触发条任意高度即展开侧边栏，触发条随即隐藏；侧边栏收起后触发条重新出现。每次展开时会尝试同步当前会话。
- **历史编辑分支识别**：编辑历史问题后，若会话接口提供节点关系和 `current_node`，目录会沿当前活动分支重建，避免将旧分支的问题混入当前目录。
- **问题与回答标题导航**：目录行由左到右依次为**序号、问题文字、三点省略号、展开三角形**，三角形紧邻右侧滚动条。点击问题文字跳转到对应提问，同时自动展开该回答的标题子目录（有标题时）；再次点击问题不会收起已展开的子目录。点击三点省略号可打开和右键相同的操作菜单；右侧三角按钮仍可独立展开或收起标题。子目录最多展示两级标题，可点击定位到已渲染的回答标题。
- **目录辅助操作**：移除行内收藏旗子；右键目录项或点击三点省略号，可选择「收藏」「复制」「添加」。收藏可再次操作取消，原有收藏状态仍按会话保存；复制完整提问；添加到「我的提示词」。支持悬停预览长提问。
- **「我的提示词」**：保存、管理常用提示词，支持 Markdown 导入/导出；在 ChatGPT 输入框输入 `#` 或 `//` 可触发提示词补全。
- **侧边栏右侧工具条**：回到顶部、切换「我的提示词」、回到底部三个按钮纵向排列在侧边栏内部右下角，按钮右边紧贴浏览器内容区域边缘。侧边栏展开时先显示，鼠标移开这组三按钮的大小区域即渐隐，重新移入原区域再显示；收起侧边栏时一并隐藏。目录滚动条也紧贴右边缘。仍支持调整侧边栏宽度、固定和自动隐藏。
- **外观与本地存储**：适配浅色/深色主题；提示词和部分目录设置保存在浏览器本地存储中。

## 支持范围与已知限制

- **主要支持**：Chrome（Manifest V3）上的 [ChatGPT](https://chatgpt.com/)。清单中同时保留 `chat.openai.com` 匹配规则。
- **尚未支持**：Microsoft Copilot。本仓库仅注册 ChatGPT 平台，不会在 Copilot 页面注入脚本。
- **网页兼容性**：ChatGPT 改动 DOM、滚动容器或会话 API 时，目录同步、回答标题提取及跳转可能需要继续适配。
- **历史分支同步**：优先使用包含节点父子关系的活动分支数据；若仅取得不含分支关系的分页消息，则无法可靠区分已废弃分支。
- **回答标题**：标题大纲从当前浏览器中已渲染的回答内容提取；未挂载的历史回答可能需要先滚动加载，纯文本回答没有可展开标题。
- **导航模式**：采用独立虚拟导航，不使用 ChatGPT 原生目录按钮，也不伪装网页的响应式宽度。
- **兼容性诊断**：默认关闭；启用后对 ChatGPT 同源接口发起额外探测请求。

## 下载安装（无需本地构建）

1. 打开 [Releases 下载页](https://github.com/PyRookie1/luna-toc-sc/releases)，选择最新的 **LunaTOC-SC Chrome** 预览版本。
2. 在 **Assets** 中下载 **`luna-toc-sc-chrome.zip`**，并**解压**到独立文件夹。不要下载 GitHub 自动附带的 `Source code (zip)`，它是未构建的源码。
3. 打开 Chrome 的 `chrome://extensions/`，开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择解压后的文件夹（该目录下应直接包含 `manifest.json`）。
5. 打开或刷新 [ChatGPT](https://chatgpt.com/) 页面。

> 注意：Chrome 不能直接加载普通 ZIP 文件，必须先解压。

## 如何使用

1. 进入 ChatGPT 对话，在视口右边缘找到 **5px 宽、上下铺满的半透明蓝色触发条**；鼠标移入即可展开目录侧边栏，短条立即隐藏；离开侧边栏后默认自动收起，短条重新显示。
2. **点击问题文字**跳转到对应的提问并自动展开该回答的标题（若有可提取标题）；**点击右侧三角形**仍可手动展开或折叠回答标题。
3. 点击展开后的标题，定位回答中的对应段落；使用搜索框过滤问题。右键目录项或点击右侧「···」，可选择「收藏」「复制」「添加」；再次收藏可取消、复制可直接粘贴文本、添加可保存至「我的提示词」。
4. 编辑某个已回答的历史问题并重新生成回答后，先将侧边栏收起，再次悬停展开以触发当前对话同步。
5. 侧边栏展开后，右下角的三个按钮先显示；鼠标移出按钮组所占区域便隐藏，鼠标移回这块区域会重新出现。按钮最右边与目录滚动条都贴视口右边缘。固定按钮仍可保持目录侧边栏展开。

## 隐私与数据处理

项目没有进行对话数据收集。目录与对话导航主要在浏览器页面内运行；「我的提示词」存储在浏览器的 `chrome.storage.local` 中。目录问题标记等临时状态保存在当前标签页的会话存储中。

## 已知限制与验证

- 目录依赖 ChatGPT 网页消息结构及同源会话接口。网页或 API 变更后，目录更新和跳转需要重新验证。
- 重复内容或含附件的提问不使用不确定的文本回退匹配；无法确定消息身份时会提示定位失败。
- 单标签页内的提示词增删改通过队列顺序写入；在不同浏览器上下文同时编辑相同内容时，Chrome 本地存储不提供事务级冲突解决。
- GitHub Actions 验证类型检查、单元测试与扩展构建；不等同于真实 ChatGPT 页面端到端验收。
