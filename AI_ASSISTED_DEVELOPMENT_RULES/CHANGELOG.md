# 规则文档变更记录

> 本文件记录 AI 辅助开发规则自身的变更。文件名不使用版本号；以 Git 提交历史和本文件追踪变更。

## 2026-10-26 — 初始建立
- 根据「软件开发」项目的既有开发制度和本轮讨论，整理需求、架构、代码修改、测试、安全、数据保护、分支与 PR、CI、发布、回滚和交付规范。
- 增加必要时主动提醒用户进行实际使用测试的强制要求，并规定提醒必须包含原因、步骤、预期结果和失败处理。
- 规定主规则保存在 ChatGPT「软件开发」项目源文件中；目标仓库中的 `AI_ASSISTED_DEVELOPMENT_RULES/` 是可审查的规则副本。
- 规定新建空 GitHub 仓库首次初始化时，在权限允许且内容通过敏感信息检查的前提下，可一次性上传项目文件和规则文件并直接提交默认分支，不必为初始化专门创建开发分支。
- 规定后续开发每次读取规则；只有规则变化或文件缺失时才同步，并在同步前比较差异，避免覆盖有效修改。
- 明确该目录只用于 AI 辅助开发，不属于软件业务源码或运行时功能；构建和打包应排除该目录。
- 本规则文件包尚需由用户上传到 ChatGPT「软件开发」项目源文件，并在实际目标仓库中按规则初始化。此记录不表示已上传到任何 GitHub 仓库或已启用 CI／分支保护。
