# 本地数据备份与恢复

本功能在 Chrome 扩展的**设置**页面中提供。无额外权限、无网络上传，不读取或导出 ChatGPT 对话正文。

## 范围与格式

生成 `luna-toc-backup-YYYY-MM-DD.json`，格式标识 `luna-toc-local-backup`，版本 `1`。
包含：
- `lumaToc:myPromptsV1`：我的提示词（ID、标题、正文、创建和更新时间）。
- `lunaToc:promptUsageV1`：提示词使用统计。
- `chatToc:aliases:v1:*`：自定义目录名称、会话/消息 ID 和账号归属标识。
- `chatToc:themeSettings`：主题设置（若只有历史主题键则按旧值导出）。
- `chatToc:sidebarPreferences`：布局、颜色和触发区设置。

不会导出扩展暂存的对话正文、Chrome 会话存储、兼容性警告、开发者诊断开关、浏览器身份凭证或任意未知存储键。仍保留提示词库已有的 Markdown 导入导出流程。备份文件可能包含私人提示词与账号、会话标识，**不要公开上传或分享**。

## 使用流程

1. 打开扩展弹出窗口，点击「设置」。
2. 在「本地数据备份与恢复」中选择「导出本地数据」，妥善保存 JSON 文件。
3. 如需恢复，选择 JSON 文件；设置页会先校验文件版本、字段、长度、大小（不超过 12 MiB）以及重复提示词 ID，再展示预览。在此之前不会改写本地数据。
4. 选择模式：
   - **合并**：按提示词 ID、会话 ID 和消息 ID 合并；同 ID 的备份记录优先，保留其他本地记录；主题和侧边栏设置采用备份值；对存在互相冲突的账号归属拒绝合并。
   - **覆盖**：以备份数据取代上述项目；未出现在文件中的旧目录别名会被删除，其他不属于备份范围的存储键保持不变。
5. 点击「确认恢复」并确认操作。恢复完毕后，可刷新已打开的 ChatGPT 标签页读取最新状态。

恢复前建议先导出并保留当前数据的独立备份。提示词已删除但使用统计尚未清理时，导出仅包含仍有对应提示词的统计（不会在导出时修改存储）；合并恢复会同步移除当前本地的孤立统计并保留有效统计。如果导入文件本身存在孤立统计，仍会拒绝导入，避免静默接受损坏的外部备份。当前版本将提示词、目录别名、使用统计、主题和侧边栏设置写入，以及备份导出/恢复，统一放入扩展后台共享串行队列。恢复期间这些新版扩展写入不会交错；旧版本脚本、未来新增的直接存储写入或其他扩展不受该队列控制，因此恢复前仍建议刷新其他 ChatGPT 标签页。显式恢复某会话的目录别名时，会同时清除该会话此前的删除标记以允许继续编辑；如恢复失败，删除标记也参与回滚。

## 异常保护与回退

解析、结构验证、读取存储失败或预计超出 Chrome 本地存储容量时，不执行写入。执行恢复前先保留所有受影响存储键的内存快照，写入后核对结果；如写入或清理失败，尝试将受影响存储键恢复为快照。若浏览器存储持续出错，自动回滚也可能失败，界面会提示保留备份文件并停止覆盖操作。**共享队列能阻止当前版本扩展自身的写入交错，但 Chrome storage 本身没有跨上下文原子事务；旧版本脚本或其他直接写入者仍可能绕过队列。它不能代替离线 JSON 备份。**

本功能的自动化验收主要覆盖版本校验、字段校验、正常导出、合并、覆盖、账号隔离及异常回滚；真实 ChatGPT 页面与人工交互不属于当前阶段验收范围。
