# LunaTOC-SC 当前技术决策

此文件仅记录本仓库现行设计，不作为原项目的历史决策日志。

## D1 — 单平台 Chrome 扩展

产品仅支持 ChatGPT 的 `chatgpt.com` 与 `chat.openai.com`。使用 Manifest V3、Vite、CRXJS 和 TypeScript。平台抽象保留为宿主 API 与 DOM 的边界，但不注册未实现的平台。

## D2 — 独立虚拟导航

目录定位依赖消息身份与当前挂载 DOM。精确 ID 匹配优先；文本回退仅用于无附件、内容唯一的提问，无法确定时报告失败。虚拟滚动通过有取消条件的视口逐步寻找目标，不调用废弃的原生目录导航策略。

## D3 — 不修改宿主响应式 API

不拦截或伪装 `window.matchMedia`。ChatGPT 的响应式布局由浏览器和网页决定。窄窗口、分屏与固定侧边栏需要真实浏览器回归测试。

## D4 — 活动分支刷新与竞态隔离

侧边栏展开时通过 ChatGPT 同源接口主动刷新。存在映射节点时按 `current_node` 追溯活动分支；否则必须完整获取分页数据后才替换目录。页面原有 `fetch` 请求带起始时间，较新快照应用后拒绝此前已启动但迟到的旧分页数据。

## D5 — 用户提示词数据完整性

保留既有 Chrome 本地存储键，以维持用户数据兼容。存储层返回对象副本，失败写入恢复原缓存，同一扩展上下文内通过队列串行化读—修改—写操作。跨标签页的同时写入不提供事务保证，属于明确的使用边界。

## D6 — 隐私与最小权限

`manifest.json` 仅申请 `storage` 权限并限定 ChatGPT 域名。对话信息用于本地目录和导航；扩展可以向 ChatGPT 同源会话 API 取回当前会话数据，不向维护者服务器传输对话或添加遥测服务。详细说明见 [PRIVACY.md](../PRIVACY.md)。

## D8 — 用户可选布局与本地背景配色

设置页提供并排与浮层两种模式。并排模式默认固定展开，仅对 ChatGPT 实际聊天主容器或带有共同顶部栏的聊天列预留侧边栏宽度；保留原生导航与媒体查询。浮层模式默认隐藏，两个模式均允许随后手动固定切换。侧边栏背景配色采用 ChatGPT 风格预设色板，不写入或反向读取 ChatGPT 的个人设置；默认背景与顶部栏使用原有浅蓝/深蓝半透明主题色并保留背景模糊，其他颜色按当前深浅主题混色。隐藏触发区在完全透明和所选色系半透明之间可选。右侧快捷工具默认收起，仅在重新进入触发空间时显示，整组可纵向移动并限制在视口内。

## D9 — 目录右键菜单操作

菜单固定按「复制、添加、收藏／取消收藏」排列。添加操作始终打开原有提示词保存弹窗，不查询已保存项，也不在目录右键菜单提供删除；收藏沿用当前会话的消息 ID 标记集合，按状态显示收藏或取消收藏，关闭菜单后再次打开即可看到最新标签。取消添加相关来源匹配代码已停用；保留用户已有提示词数据。

## D7 — 测试与发布

所有功能变更添加 Vitest 回归用例。CI 对 PR 与主分支执行类型检查、单元测试、构建、Manifest 资源检查及 ZIP 验证；仅主分支发布预览包。涉及 ChatGPT 页面结构的更改必须另行进行手动浏览器验收。

## D10 — 会话生命周期以 ChatGPT 为准

在每次打开或刷新 ChatGPT 页面时仅执行一次会话引用校验，不启用后台轮询。当前页成功发起的删除操作可即时清理会话缓存与标签页收藏；归档不触发清理。启动校验要求 Chrome 标签页中收藏记录有与当前 ChatGPT 登录用户相同的账号绑定，且服务端明确返回不存在状态；旧版无归属记录、网络错误、未登录和无法判定的状态必须保留。活动分支之外的消息不能因缺席当前目录而被认定删除。扩展维护的导航快照有容量上限和显式删除接口；获取权威快照失败时保留旧数据但标记未验证。独立保存的「我的提示词」不随聊天删除；其使用统计以现存提示词 ID 为准执行本地核对。
