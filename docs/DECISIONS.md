# LunaTOC-SC 当前技术决策

此文件仅记录本仓库现行设计，不作为原项目的历史决策日志。

## D1 — 单平台 Chrome 扩展

产品仅支持 ChatGPT 的 `chatgpt.com` 与 `chat.openai.com`。使用 Manifest V3、Vite、CRXJS 和 TypeScript。平台抽象保留为宿主 API 与 DOM 的边界，但不注册未实现的平台。

## D2 — 独立虚拟导航

目录定位依赖消息身份与当前挂载 DOM。精确 ID 匹配优先；文本回退仅用于无附件、内容唯一的提问，无法确定时报告失败。虚拟滚动通过有取消条件的视口逐步寻找目标，不调用废弃的原生目录导航策略。

## D3 — 不修改宿主响应式 API

不拦截或伪装 `window.matchMedia`。ChatGPT 的响应式布局由浏览器和网页决定。窄窗口、分屏与固定侧边栏需要真实浏览器回归测试。

## D4 — 活动分支刷新与竞态隔离

侧边栏展开时通过 ChatGPT 同源接口主动刷新。存在映射节点时按 `current_node` 追溯活动分支；否则必须完整获取分页数据后才替换目录。页面原有 `fetch` 请求带起始时间，较新快照应用后拒绝此前已启动但迟到的旧分页数据。

## D5 — 用户提示词数据完整性

保留既有 Chrome 本地存储键，以维持用户数据兼容。存储层返回对象副本，失败写入恢复原缓存，同一扩展上下文内通过队列串行化读—修改—写操作。跨标签页的同时写入不提供事务保证，属于明确的使用边界。

## D6 — 隐私与最小权限

`manifest.json` 仅申请 `storage` 权限并限定 ChatGPT 域名。对话信息用于本地目录和导航；扩展可以向 ChatGPT 同源会话 API 取回当前会话数据，不向维护者服务器传输对话或添加遥测服务。详细说明见 [PRIVACY.md](../PRIVACY.md)。

## D8 — 用户可选布局与本地背景配色

设置页提供并排与浮层两种模式。并排模式默认固定展开，仅对 ChatGPT 实际聊天主容器或带有共同顶部栏的聊天列预留侧边栏宽度；保留原生导航与媒体查询。浮层模式默认隐藏，两个模式均允许随后手动固定切换。侧边栏背景配色采用 ChatGPT 风格预设色板，不写入或反向读取 ChatGPT 的个人设置；默认背景与顶部栏使用原有浅蓝/深蓝半透明主题色并保留背景模糊，其他颜色按当前深浅主题混色。隐藏触发区在完全透明和所选色系半透明之间可选。右侧快捷工具默认收起，首次触碰右缘仅展开侧边栏，之后离开并重新进入右缘、停留 500ms 才按指针高度显示工具；不再支持拖动，键盘入口为侧边栏内的 `Alt+Shift+J`。

## D9 — 目录右键菜单操作

菜单固定按「复制文字、添加tips、编辑文字、回到顶部、回到底部」排列，存在本地别名时再提供「恢复原文」。复制和添加使用 ChatGPT 原始消息内容，添加继续打开提示词保存弹窗。回到顶部／底部由被右键选中的消息 ID 定位该轮 ChatGPT 问答的起始用户消息与末尾助手回答，不作用于整个侧边栏或全局对话边界；回答尚未渲染时回退到该用户消息末尾。保留虚拟列表查找、原始消息身份、搜索状态和正常左键的标题展开行为。收藏功能、收藏导致的目录高亮以及跨回答保持展开的逻辑彻底删除，因为确认不存在需要迁移的历史收藏数据。

## D11 — 本地目录文字与右缘动态按钮

目录文字重命名仅是按永久会话 ID、消息 ID 存储在 Chrome 本地存储的显示别名；右键第三项在当前行显示高度自适应的多行文本区，随换行和宽度变化显示完整文字；Enter 提交、Shift+Enter 换行、Esc 取消、失焦提交，写入失败保留原位编辑和草稿；目录跳转、复制和提示词添加继续使用 ChatGPT 原始内容。目录右键「编辑文字」直接原位编辑，已有别名时提供「恢复原文」；对临时路由不允许持久重命名；搜索可匹配别名或原文。别名参加 D10 的会话启动校验与删除联动，未知账号及网络失败不执行自动删除。三个导航按钮不使用固定底部坐标、拖动或存储位置；首次鼠标触边仅展开侧边栏；离开右缘后再次进入且持续停留 500ms 才在当前指针高度显示工具组，边缘退出会取消计时；点击期间保持位置，并裁切至视口内。

## D12 — 回答目录三级与缺级压缩

回答目录最多使用当前回答中实际存在的三个标题级别，按原生 H1–H6 从浅到深选择；缺少的中间等级不产生空父节点，其余等级压缩为 1–3 级显示。保留 DOM 出现顺序以及原生 headingLevel + text + occurrence 描述符以确保重复标题仍可精确跳转。第四种及之后更深的标题级别不纳入目录。

## D7 — 测试与发布

所有功能变更添加 Vitest 回归用例。CI 对 PR 与主分支执行类型检查、单元测试、构建、Manifest 资源检查及 ZIP 验证；仅主分支发布预览包。涉及 ChatGPT 页面结构的更改必须另行进行手动浏览器验收。

## D10 — 会话生命周期以 ChatGPT 为准

在每次打开或刷新 ChatGPT 页面时仅识别一次当前登录账号，不启用后台轮询。当前页明确成功的删除操作即时清理对应导航缓存与目录别名；归档不触发清理。由于单数/复数会话接口兼容性和权限差异，单个 GET 的 404/410 不能证明会话已删除，跨设备删除尚不自动回收别名。无归属记录、网络错误、未登录和无法判定状态保留本地数据。活动分支之外的消息不能因缺席当前目录而被认定删除。扩展维护的导航快照有容量上限和显式删除接口；获取权威快照失败时保留旧数据但标记未验证。独立保存的「我的提示词」不随聊天删除；其使用统计以现存提示词 ID 为准执行本地核对。

## D13 — 维护期保守回收、异步一致性与界面回归

单次会话存在性请求失败不能触发本地别名删除；启动请求只核对当前账号身份，观察到页面内成功删除操作才能清理。单扩展上下文内的别名写入与删除排队，删除标记阻止晚到写入重新创建本地记录；跨标签页没有 Chrome 存储 CAS 事务，需后续独立机制解决。刷新超时或失败不视为已验证；右键菜单使用真实高度定位并限制滚动区域，隐藏标题不计入三级提取，已连接但内容更改的标题失效后重新提取。旧主题键在迁移完成后清理。侧边栏内 Alt+Shift+J 为隐藏导航按钮提供键盘入口。
